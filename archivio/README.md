# Archivio

Qui stanno i documenti della versione 1.3 di ESPOSIZIONE e il lavoro fatto intorno a essa, fino al 23 settembre 2026. Da quella data il riferimento del progetto è [`ESPOSIZIONE-DESIGN.md`](../ESPOSIZIONE-DESIGN.md), il documento di design 2.0, che riprende da qui le idee migliori e riprogetta il resto. L'appendice D del documento di design dice che cosa è rimasto, che cosa è cambiato e che cosa è uscito.

Questi file non si aggiornano più. Restano per chi vuole capire da dove vengono le scelte della 2.0.

| File | Che cos'era |
|---|---|
| `ESPOSIZIONE-1.3.md` | la specifica 1.3, con le correzioni del 23 settembre 2026 |
| `concept/` | le presentazioni della 1.3, in italiano e in inglese |
| `pdf/` | i PDF della 1.3 e delle presentazioni; la catena Typst attuale non li ricostruisce più |
| `CONTROANALISI-1.2.md` | il verbale che portò dalla 1.2 alla 1.3 |
| `ISTRUZIONI-riconciliazione.md` | come si portava un progetto dalla 1.1 alla 1.2 |
| `ROADMAP.md` | il piano per misurare la 1.3, mai eseguito, con l'addendum del ritardo |
| `ROADMAP-STRUMENTO.md` | il piano per trasformare InteractiveWriter nello strumento della 1.3 |
| `ANALISI-FAVELLA.md` | che cosa il progetto FAVELLA 1 insegnava alla 1.3 |
| `ANALISI-CRITICITA-1.3.md` | i ventuno rilievi alla 1.3 che hanno portato alla riscrittura |
